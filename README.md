# CheatSheet

边玩游戏边看攻略的**置顶小窗播放器**。

把攻略视频放进一个置顶小窗,用全局热键随时控制,不打断游戏操作。

## 特点

- **窗口只有画面和一条贴着底边的进度条** —— 没有标题栏、没有多余按钮
- **控制条在屏幕正上方**,平时自动收起,**鼠标移到屏幕顶端才出现**;
  点它不会抢走游戏的焦点(带 `WS_EX_NOACTIVATE`),游戏不会被切出全屏
- **全局热键**在游戏全屏、窗口失去焦点时一样生效,并且**可以自己改键**(支持单键,如 `F5`)
- **画面可以半透明**,半透明时能透出后面的游戏画面(进度条也跟着一起淡)
- 支持拖放即播、多文件播放列表、倍速、音量、静音、窗口透明度、等比例拖动

## 下载

到 [Releases](../../releases) 下载 `CheatSheet-v*-win-x64.zip`,解压后运行 `CheatSheet.exe`。

> 需要安装 **.NET 10 桌面运行时**。

## 用法

| 操作 | 怎么做 |
|---|---|
| 播放视频 | 把视频文件(或整个文件夹)**拖到窗口里**,或点控制条的打开按钮 |
| 显示控制条 | 把鼠标移到**屏幕最顶端** |
| 移动窗口 | 在画面上按住拖动 |
| 调整窗口大小 | 拖窗口的边或角 |
| 调音量 | 在画面上滚轮,或控制条上的音量条 |
| 打开设置 | 控制条最右边的齿轮图标 |

设置窗口里可以改:**画面透明度、音量、播放倍速、全部全局热键、等比例拖动**。

## 默认全局热键

| 功能 | 热键 |
|---|---|
| 播放 / 暂停 | `Ctrl+Alt+Space` |
| 快退 | `Ctrl+Alt+Left` |
| 快进 | `Ctrl+Alt+Right` |
| 窗口置顶 | `Ctrl+Alt+T` |
| 画面透明度 − / + | `Ctrl+Alt+Z` / `Ctrl+Alt+X` |

**快进 / 快退的两种按法**:快速点一下 = 跳 5 秒;按住不放 = 切 2 倍速播放,松手恢复原来的倍速。

所有热键都能在设置里改,也支持不带 Ctrl/Alt 的单键。建议单键只给 `F1`-`F12` 这类功能键 —— 全局热键会抢占系统输入,绑成 `Space` 的话在任何程序里按空格都会被它截走。

## 从源码构建

```bash
git clone https://github.com/wkrs15/CheatSheet.git
cd CheatSheet
dotnet build
dotnet run
```

也可以直接把视频路径当参数传进去:

```bash
dotnet run -- "D:\videos\guide.mp4"
```

**技术栈**:C# / WPF / .NET 10 + [HandyControl](https://github.com/HandyOrg/HandyControl)(UI 主题)、`MediaElement`(播放)、Win32 `RegisterHotKey`(全局热键)。

## 已知限制

- 播放引擎是 WPF 自带的 `MediaElement`,所以:
  - **2 倍速时没有声音**(底层变速会静音),切换瞬间也会卡一下;
  - `mkv` / `hevc` 等格式能否播放取决于系统装没装对应解码器;
- **不支持全屏**(最大化也会被自动还原)—— 目的是始终保持"小窗 + 控制条"这套形态。
